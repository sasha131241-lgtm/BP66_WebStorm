# Учебный проект: Student CRM (React)

Проект представляет собой клиентское приложение на React для управления и отображения списка студентов.

## Реализованный функционал

1. **Компонент списка студентов (`StudentsList`)**: выводит всю коллекцию данных и проверяет её на наличие элементов.
2. **Передача данных через props**: компоненты получают необходимые свойства (имя, возраст, статус) от родителей.
3. **Карточки студентов (`StudentCard`)**: отдельные блоки для отображения профиля каждого учащегося.
4. **Статус обучения (`StudyStatus`)**: отображает текущий статус (`[Активен]` / `[Пауза]`).
5. **Условное оформление**: динамический вывод метки «Несовершеннолетний студент» при возрасте менее 18 лет (`id: 5`, возраст 17).
6. **Сообщение при пустом списке**: обработка сценария с отсутствием данных.
7. **Динамический подсчет**: общее количество студентов вычисляется автоматически на основе длины массива.
8. **Компонент Footer (`Footer`)**: подвал сайта.
9. **Модульная структура**: разделение кода на компоненты и изоляция статических данных.
